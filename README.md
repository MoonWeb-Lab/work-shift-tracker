## ⚡ Функционал системы

### 1. Telegram Mini App (Встроенное веб-приложение)
- **Интерактивный календарь смен:**
  - Одно нажатие переключает статус дня: `🟢 Полная смена` ➔ `🟡 Полдня (0.5)` ➔ `⚪ Выходной`.
  - Долгое нажатие открывает настройку дня (время выхода на полдня, персональная ставка, заметка к смене).
- **Счётчики и расчёт зарплаты в реальном времени:**
  - 💰 **Фактически заработано** за текущий месяц на данный момент.
  - 📈 **Прогноз к зарплате** — сколько денег будет начислено к выплате с учётом запланированных смен.
  - ⏳ **Счётчик «До зарплаты осталось»** — точное количество календарных дней и рабочих смен до дня выплаты.
  - ⏱️ **Счётчик часов и смен** — полные смены, смены на полдня и суммарное количество отработанных часов.
  - 📊 **Недельный срез** — заработок и оставшиеся смены на текущей неделе.
- **Гибкие настройки:**
  - Ставка за полную смену и полсмены.
  - Выбор валюты (`BYN`, `RUB`, `USD`, `EUR`).
  - Время выхода на полдня (например, `09:00 - 14:00`, `14:00 - 20:00` или своё).
  - Число зарплаты и аванса.
  - Время утренних и вечерних уведомлений.
- **Тактильная отдача:** нативная виброотдача Telegram (`HapticFeedback`) при переключении смен и сохранении.

---

### 2. Telegram Bot (Python 3.14 + aiogram 3 + APScheduler)
- **Кнопка «Меню» в Telegram:** нативная кнопка слева от поля ввода, открывающая Mini App в один клик.
- **Команды:**
  - `/start` — Приветствие, настройки пользователя и запуск Mini App.
  - `/status` — Текстовая сводка заработка, смен и дней до зарплаты.
  - `/shift` — Быстрая отметка смены прямо в чате кнопками без перехода в Mini App.
  - `/settings` — Просмотр и изменение ставок, дат выплат и расписания.
  - `/help` — Справка и возможности.
- **Умные уведомления (Планировщик):**
  - **Утреннее напоминание (08:00):** если сегодня смена (полная или на полдня с указанием времени выхода).
  - **Вечернее напоминание (21:00):** напоминание об окончании смены и фиксации заработка.
  - **За день до зарплаты:** уведомление о сумме начисления и готовности к выплате.
  - **В день зарплаты:** праздничное уведомление с итоговым расчётом заработанных денег.

## 🚀 Запуск бота локально

1. Убедитесь, что установлен Python 3.10+:
   ```bash
   pip install aiogram aiohttp apscheduler
   ```
2. Запустите файл `start_bot.bat` или выполните команду:
   ```bash
   python bot/main.py
   ```
